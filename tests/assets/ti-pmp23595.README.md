These fixtures are from the **actual PMP23595 board shown in PR #187**.

- Source: Texas Instruments PMP23595 CAD/CAE files
  [SLVMEP2A](https://www.ti.com/lit/zip/SLVMEP2), `PMP23595.PcbDoc`.
- Original PcbDoc SHA-256:
  `18913410812b0993e4c8c3a00a489335d0fa58d27b79ec02e1294a8a6471e0f6`.
- `ti-pmp23595.circuit.json` contains the full production importer output
  (`altium-to-circuit-json` commit `149bd7d`), including every imported pad,
  trace, via, copper pour, component, and annotation. The original 5,168
  elements are unchanged. Two zero-size annotation owners are appended for
  `pcb_component_altium_board_graphics` and `pcb_component_altium_65535` to
  satisfy the exporter's existing owner validation. The screenshots in PR #187
  use exactly this same workaround; terminal pad geometry is untouched.
- `ti-pmp23595-original-upper.svg` and `ti-pmp23595-original-lower.svg` are
  the original native board rendered with `altiumts` commit
  `8db22cf449c7bf6584a968b4913be4e1bd4a93ad`, layers `MID1` and `MULTILAYER`,
  and native mil viewports `(2300, 3550, 1450, 950)` and
  `(1250, 1350, 1500, 1150)`, respectively. They supply the visual reference
  without downloading the TI archive during every test run. These are the
  same terminal regions shown in PR #187.

The comparison maps source `MID1` to exported `MID-LAYER2` by physical layer
position and compensates for the exporter's board-origin translation.

T500 and T502 have `rect_ccw_rotation: 90`; T501 and T503 have
`rect_ccw_rotation: 270`. Their copper size is 17.272 × 12.7 mm and drill
diameter is 6.4516 mm. The separate existing drill-offset mismatch remains
visible in this reproduction.
